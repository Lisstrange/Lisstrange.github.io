Гитара + голос в Телемосте через Audient iD14 и Reaper

Настройка звука для созвонов, где нужно одновременно говорить и играть: уроки, репетиции. Теория и порядок тем по гитаре в Игра на гитаре, конспекты занятий в уроки джазовой гитары с Артёмом Крикуновым. Железо и разделение рабочей и игровой зоны в проекте Изоляция рабочей и игровой зоны.

TL;DR

Гитара и голос заходят в Reaper двумя отдельными дорожками (Input 1 и Input 2), у каждой своя цепочка FX. Мастер Reaper отправляет итоговый звук в BlackHole 2ch, который Телемост берёт как микрофон, и в iD14 Output 3/4 на мониторинг в наушниках. Сам Reaper работает через Aggregate Device (iD14 + BlackHole).

1. Проблема и причины

Гитару плохо слышно в Телемосте, хотя она подключена к Audient iD14. Причины:

#ПричинаСуть
1VoIP-клиент берёт только первые каналы устройстваТелемост не даёт выбрать входной канал. У iD14 12 входов, клиент видит фактически только Input 1/2
2Шумоподавление, echo cancellation и AGCРечевая обработка считает гитару шумом и режет её
3Низкий gain / gain stagingСигнал на входе около −45…−50 dBFS, это слишком тихо
4Нет микшированияГолос и гитара не сведены в один сигнал с контролируемым балансом

Ограничение, которое не обойти

Телемост кодирует звук Opus в речевом профиле (моно, агрессивная обработка). Даже при идеальной настройке гитара будет звучать хуже, чем в DAW. Для уроков и репетиций лучше подходят инструменты с music mode: Zoom Original Sound for Musicians, Sonobus, JamKazam.

2. Итоговая схема

Mic 1 (гитара) → Reaper: Track "Guitar" [FX] ─┐
                                              ├→ MASTER ─┬→ BlackHole 2ch → Телемост (микрофон)
Mic 2 (голос)  → Reaper: Track "Voice"  [FX] ─┘          └→ iD14 Out 3/4 (DAW 3+4) → наушники

Телемост (динамики) → iD14 Out 1/2 (DAW 1+2) → наушники

Компоненты

КомпонентРоль
Audient iD14 (MkI)Аудиоинтерфейс. Mic 1 = гитара, Mic 2 = голос
iD Mixer (приложение Audient iD)Аппаратный микшер мониторинга (Master Mix, Cue A/B, Loopback)
BlackHole 2chВиртуальное аудиоустройство-«труба»: всё, что пишется в его выход, доступно на его входе
Aggregate DeviceОбъединяет iD14 и BlackHole в одно устройство для Reaper
ReaperМикширование и обработка (FX) голоса и гитары
ТелемостМикрофон = BlackHole 2ch, динамики = Audient iD14

3. Установка BlackHole

Альтернатива: инсталлятор .pkg с https://existential.audio/blackhole/ (бесплатно, просят email).

Проверка, что драйвер установлен:

Если устройство не появилось в системе, перезапустите CoreAudio (или перезагрузите Mac):

Скачать .pkg недостаточно

Его нужно запустить и пройти установщик. Если macOS спросит, разрешите в System Settings → Privacy & Security.

4. Aggregate Device

Audio MIDI Setup (Spotlight → «Audio MIDI Setup» / «Настройка Audio-MIDI», либо Applications → Utilities).

  1. Кнопка + внизу слева → Create Aggregate Device.
  2. Отметить в колонке Use два устройства: сначала Audient iD14, затем BlackHole 2ch.
  3. Clock Source: Audient iD14
  4. Sample Rate: 48,0 kHz
  5. Drift Correction: включить только у BlackHole 2ch.
  6. Переименовать: двойной клик по названию в левом списке → iD14 + BlackHole.

Раскладка каналов агрегата

НаправлениеКаналыУстройство
Inputs1–12Audient iD14
Inputs13–14BlackHole 2ch
Outputs1–6Audient iD14
Outputs7–8BlackHole 2ch

Агрегат должен показывать 14 ins / 8 outs.

Пункты, которые не нужны

  • Multi-Output Device работает только на выход.
  • Virtual AVB Device отдаёт сетевое аудио по Ethernet.
  • Aggregate Device сам по себе не микширует и не переставляет каналы, он только склеивает их подряд.

5. Reaper: устройство

Reaper → Settings (⌘ + ,) → Audio → Device

ПараметрЗначение
Allow use of different input and output devicesснять галочку
Audio DeviceiD14 + BlackHole (Aggregate Device)
Request sample rateвключить, 48000
Request block sizeвключить, 128 (около 6–8 ms round-trip; при щелчках увеличить до 256)

Apply → OK

Затем в родительском пункте Audio снять Close audio device when stopped and application is inactive. Иначе звук пропадёт, когда фокус переключится на Телемост.

Если агрегата нет в списке

Полностью закройте Reaper (⌘ + Q) и откройте снова: список устройств он перечитывает при запуске.

Признак, что выбран не агрегат

В Master → ROUTE → Add new hardware output видны только Output 1–2 (выбран BlackHole) или 1–6 (выбран iD14). У агрегата выходов должно быть 8.

Если macOS спросит доступ к микрофону для Reaper, разрешите. Проверить можно в System Settings → Privacy & Security → Microphone → REAPER.

6. Reaper: дорожки

Создать две дорожки (⌘ + T):

ДорожкаInputRecord modeMonitoring
GuitarMono → Input 1Record: disable (input monitoring only)On
VoiceMono → Input 2Record: disable (input monitoring only)On

Как настроить:

  1. Красная кнопка Record Arm на дорожке → включить.
  2. Поле входа под именем дорожки → Input: Mono → Input 1 (или 2).
  3. Правый клик по Record Arm → Record: disable (input monitoring only). Звук проходит через дорожку, на диск ничего не пишется.
  4. Иконка динамика справа от Record Arm → Monitor Input: On (у иконки появятся «волны»).
  5. Переименовать дорожки: двойной клик по имени.

Баланс гитары и голоса выставляется фейдерами дорожек.

7. Reaper: выходы мастера

Все дорожки сводятся на шину Master, и её hardware outputs определяют, куда уходит итоговый звук.

Микшер: View → Mixer (⌘ + M) → канал MASTER → кнопка с цветными диагональными полосками (подпись ROUTE, между S и FX).

В разделе Audio Hardware Outputs:

  1. Удалить выход по умолчанию (Delete).
  2. Add new hardware output… → Output 3 / Output 4 (Audient iD14): мониторинг.
  3. Add new hardware output… → Output 7 / Output 8: BlackHole → Телемост. В списке он может называться Output 1 (BlackHole 2ch) / Output 2 (BlackHole 2ch).
ВыходКудаЗачем
iD14 Out 1/2DAW 1+2 в iD MixerНе использовать, сюда приходит системный звук (Телемост)
iD14 Out 3/4DAW 3+4 в iD MixerМониторинг обработанного звука
BlackHole 1/2 (агрегат 7/8)ТелемостТо, что слышат собеседники

У каждого hardware output свой фейдер

Громкость в наушниках (3/4) можно убавить, не меняя уровень в звонке (BlackHole).

8. iD Mixer: мониторинг

Приложение Audient iD (скачать на audient.com → Support → Downloads).

Чтобы выбрать, какой микс редактировать, кликните MASTER MIX или CUE A в правой панели. Заголовок над фейдерами показывает, какой микс сейчас активен.

MASTER MIX (наушники)

КаналИсточникПоложение
Mic 1Гитара (сухая)∞ (вниз)
Mic 2Голос (сухой)∞ (вниз)
DAW 1+2Звук macOS (собеседники в Телемосте)По вкусу
DAW 3+4Обработанные гитара и голос из Reaperоколо 0 dB
DAW 5+6Не используется∞

Почему Mic 1 и Mic 2 вниз

Если оставить их поднятыми, сухой сигнал без задержки и обработанный из Reaper с задержкой в несколько миллисекунд будут звучать одновременно. Получится comb filtering (фазовые искажения, «фланжер»).

Также проверьте:

  • Ø (polarity invert) на каналах Mic 1 и Mic 2 выключен, если это не сделано намеренно.
  • macOS: System Settings → Sound → Output = Audient iD14.

9. Gain staging

ТочкаЦелевой уровень пиков
Входы iD14 (индикаторы Mic 1/2 в iD Mixer)−12…−6 dBFS при громкой игре или речи
Дорожки Reaper−12…−6 dB
Master Reaperне выше −3 dB
  • Тихий сигнал поднимайте ручками gain на самом iD14, а не фейдерами в Reaper.
  • Красный пик +0.0 / +0.1 означает клиппинг, нужно убавить gain. Индикатор пика сбрасывается кликом по нему.
  • Для электрогитары включите Hi-Z / INST, если гитара подключена в инструментальный (DI) вход.

10. Телемост

ПараметрЗначение
МикрофонBlackHole 2ch
ДинамикиAudient iD14
Шумоподавлениевыключить, если опция доступна в этой версии клиента

Десктоп-клиент вместо браузера

В браузере WebRTC-обработка (noise suppression, AGC, echo cancellation) включена жёстко, отключить её нельзя.

11. Обработка (FX)

Кнопка FX на дорожке → добавить плагины. Зелёная кнопка означает, что обработка работает, красная значит bypass (снимается кнопкой питания рядом).

Голос (встроенные ReaPlugs)

#ПлагинНастройка
1ReaEQHigh-pass около 80–100 Hz; лёгкий подъём около 3–5 kHz для разборчивости
2ReaCompRatio 3:1, gain reduction около 3–6 dB
3ReaGate (опционально)Срезает фон между фразами, раз шумоподавление Телемоста выключено

Электрогитара (DI)

#ПлагинКомментарий

Альтернатива: IK AmpliTube CS (бесплатная версия).

12. Чек-лист перед звонком

  • iD14 подключён, Output macOS = Audient iD14
  • Запущен Reaper, открыт проект telemost.rpp
  • В Reaper Audio Device = iD14 + BlackHole
  • Дорожки Guitar и Voice в режиме monitoring On, индикаторы реагируют
  • В iD Mixer, Master Mix: Mic 1/2 внизу, DAW 3+4 поднят
  • Телемост: микрофон BlackHole 2ch, динамики Audient iD14, шумоподавление выключено
  • Проверка микрофона в Телемосте: слышны и голос, и гитара
  • Reaper остаётся запущенным на протяжении всего звонка

14. Приложение: Loopback iD14 (альтернативная схема)

До перехода на раздельную обработку всё было настроено так. Схема подходит, если нужен простой микс без отдельных FX.

Факты про iD14 MkI

  • Loopback у iD14 MkI есть, настраивается в меню приложения iD в верхней строке macOS → Set Loop-back Source, а не в System Panel.
  • Loopback приходит в систему на входы 11/12 (проверено тестом).
Каналы iD14 (input)Что это
1–2Mic 1 / Mic 2 (вкл. DI)
3–10Цифровые входы (ADAT/S/PDIF), не используются
11–12Loopback

Настройка

  1. Меню iD → Set Loop-back Source → CUE A. Не MASTER MIX: в нём обычно есть системный звук, это даёт эхо в звонке.
  2. iD Mixer → клик CUE A: Mic 1 и Mic 2 около 0 dB, pan в центр; DAW 1+2 / 3+4 / 5+6 в ∞; ручка CUE MASTER вправо (около 0). Если она на минимуме, в Loopback ничего не попадёт.
  3. Reaper (вход iD14, выход BlackHole): одна дорожка, Input Stereo 11/12, monitoring On.
  4. Телемост: микрофон BlackHole 2ch.

Как проверить, на каких каналах Loopback

  1. В Reaper две дорожки: Input 1/2 и Input 11/12.
  2. Cue A: Mic 1/2 вниз, DAW 1+2 вверх, в браузере играет музыка.
  3. Где появилась музыка, там и Loopback: сырые входы не могут содержать системный звук.
  4. После теста вернуть DAW 1+2 в Cue A обратно в ∞.

Минус схемы

Голос и гитара приходят уже смешанными, поэтому обрабатывать их по отдельности нельзя. Для отдельных FX используйте основную схему (разделы 4–11).
